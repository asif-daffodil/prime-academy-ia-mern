# MERN Course

Course materials and practice work for learning web development on the path to the MERN stack (MongoDB, Express.js, React, and Node.js).

## About this repository

The material currently in this repository focuses on the front-end foundations: HTML and CSS lessons, demonstrations, and student assignments from day 01 through day 07. MERN backend and React projects are not included yet.

## Course contents

| Folder | Topics and materials |
| --- | --- |
| `day-01/` | HTML basics and introductory examples |
| `day-02/` | HTML structure and semantic elements, media, and CSS methods |
| `day-03/` | CSS positioning and transforms, with team-page assignments |
| `day-04/` | Flexbox, CSS Grid, responsive layouts, and animation assignments |
| `day-05/` | Additional CSS practice, fonts, icons, video, animation, and responsive design |
| `day-06/` | Sass/SCSS practice and page-building assignments, including Figma-to-HTML work |
| `day-07/` | A styling practice page with SCSS and generated CSS |

Some folders contain individual classwork or homework submissions. Keep each page's related styles, images, fonts, and other assets alongside that page.

## Getting started

These lessons are static web pages; there is no package installation or build step required for the current materials.

1. Clone or download this repository.
2. Open a lesson's `index.html` file directly in a web browser. For example, start with `day-01/index.html`.
3. Continue through the day folders and open their nested `index.html` files for additional examples and assignments.

For a better editing workflow, open the repository folder in a code editor and use a local static-file server or the editor's live-preview extension.

## Learning path

Work through the lessons in order, experiment with the examples, and complete the assignments in the `hw/` folders. As the course progresses, this repository can be extended with JavaScript, React, Node.js, Express.js, and MongoDB projects.
