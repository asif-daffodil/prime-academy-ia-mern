# Project Title :- Fashion Landing Page

# Description :-A responsive fashion e-commerce landing page built with HTML and Tailwind CSS.

# Features :-
1:- Fully responsive design
2:- Hero section with bold typography
3:- Brand logos strip
4:- New arrivals product grid
5:- Payday sale banner
6:- App download section
7:- Newsletter signup
8:- Complete footer with social links

# Tech Stack
1:- HTML5
2:- Tailwind CSS (via CDN)
3:- Google Fonts (Montserrat)
4:- Inline SVG icons
